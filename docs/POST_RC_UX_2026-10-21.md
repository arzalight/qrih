Filtra operación/municipio/área en servidor, excluye ID y ordena por fecha; revisa nuevamente elegibilidad y ordena con matching antes de tomar3. La búsqueda de candidatas se limita a1000; no afirmar ranking exhaustivo de un universo superior. Sólo se firman las hasta3portadas seleccionadas, con autorización existente y TTL público10min. Sin área/municipio/operación no se inventa compatibilidad. Cero candidatas muestra vacío honesto; error de consulta indica indisponibilidad y no rompe la ficha; error de firma deja tarjeta sin foto, nunca URL pública fallback. Rejilla3/2/1columnas; si sólo hay una candidata, no se estira a todo el escritorio.

Portadas administrativas se calculan sólo para la lista filtrada que ya veía el administrador; no se altera consulta, filtros, estados, paginación o permisos. Componente cliente recibe URL efímera; no llama Storage ni a la ruta de renovación exclusiva del propietario. Si caduca/falla, muestra fallback; recargar la página obtiene firmas nuevas con permisos vigentes. No nueva renovación automática implementada por este lote.
